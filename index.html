Private-use backup utility

YAT Archive Backup

A private utility operated by Dmitry Bykov to save selected archive backups to his Google Drive and verify that those backups can be downloaded and restored.

How it works

The owner authorizes Google Drive access. A server creates dated backup files and accompanying verification records, then reads the uploaded files back to check their integrity. This is not a public file-sharing service.

Google Drive permissions

The application requests drive.file: access to files it creates or files explicitly made available to the application. It does not request unrestricted access to the entire Drive.

Account control

Only the owner's configured Google account is intended to use this utility. Publishing this information site does not make backups public or give visitors access to the application.

Read the privacy policy for details about data handling and revoking access.
